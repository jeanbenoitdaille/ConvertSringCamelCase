# Convert String to Camel Case

Exercice JavaScript consistant à convertir une phrase en chaîne `camelCase`.

## Objectif pédagogique

Manipuler :

- `split()` ;
- `shift()` ;
- `toLowerCase()` et `toUpperCase()` ;
- `slice()` ;
- les tableaux ;
- la boucle `for...of` ;
- la concaténation de chaînes.

## Exemple

La phrase :

```text
Phrase en camel case
```

devient conceptuellement :

```text
phraseEnCamelCase
```

## Fichier principal

`index.js`

## Exécution

```bash
node index.js
```
